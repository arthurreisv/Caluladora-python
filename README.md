# Calculadora Python

Calculadora com menu interativo no terminal em Python, com soma, subtração,
multiplicação e divisão. Com tratamento de exceção de divisão por 0 e entrada de
letras no lugar de números.

## Como rodar

    python calculadora.py

## Exemplo de uso

    (0) SAIR
    (1) SOMA
    (2) SUBTRACAO
    (3) MULTIPLICACAO
    (4) DIVISAO
    Selecione uma operacao: 1   # Escolha um número de 0 a 4
    Digite o valor de A: 2      # Escolha o primeiro valor da operação
    Digite o valor de B: 3      # Escolha o segundo valor da operação
    A + B = 5.0                 # Impressão do resultado
